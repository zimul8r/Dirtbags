How To Use This Character Sheet

Dirtbags! Third Party License: https://www.thedungeonskey.com/dirtbags-third-party-license/

Sheet Tabs

At the top of the page are three buttons: PC, EQUIPMENT, THREATS, and HELP.

The PC button brings you to the main player character sheet. The EQUIPMENT button brings you to the gear and weapons sheet. The THREATS button brings you to the monsters sheet. The HELP button brings you to these directions.

The Player Character Sheet

Character Details Panel

The left-most panel contains a number of fields for recording character details.

The ROLE field is a special drop-down menu. If the field is empty, the drop down lists the standard Dirtbags! roles and the player can select a role. Otherwise, the player can type a custom role name into the field.

Once a player types anyting into the ROLE field, they have to clear the field to see the drop-down options again.

The TRAITS, P.O. (pardonable offences), and FALLOUT fields have vertical sliders in the event the player has more than 3 lines of entries to record.

Body Panel

The middle panel contains the body health and injuries details.

Each body section has a pair of number fields for current hits remaining / total hits. There is also a status checkbox for each type of injury that body part may suffer from.

Stats and Weapons Panel

The right-most panel contains current value and total value pairs for tracking the character statistics (BONES, CUNNING, and NERVES) and M.I.L.K. uses, and the current load carried and maximum carrying capacity. It also provides fields to record the number of kills and total credits the character has.

At the bottom of this panel, the player can enter up to 4 of their currently carried weapons, along with those weapons statistics for ammo CAPACITY, current AMMO level, CALIBER (L, M or H), and MODE (1=Single-action, S=semi-automatic, and A=automatic). The radio button to the left of each weapon designates the one currently in use. These fields work with the AMMO dice pools to manage the available dice.

When a weapon is selected, the AMMO POOL and AMMO RESERVE boxes are set to the selected weapon's current values, and the AMMO box is emptied.

When the player fires the weapon, the AMMO field of the weapon table will update to reflect the used ammo.

When the player uses the RELOAD button, the weapon's AMMO field in the table will be reset to full CAPACITY.

If the player rolls two 1's in a single FIRE roll, this triggers a firearms malfunction. In the weapon table, the weapon in question will display a JAMMED button across the table. When the player takes an action to clear the weapon jam, they can click the JAMMED button to remove the condition.

IMPORTANT: When first creating your character, after populating your statistics and weapons in this panel, click the REPLENISH and RELOAD buttons in the dice pools to initialize those pools.

Custom Checkboxes

There are three custom checkbox sections the player can use to track magazines, energizers, or other expendables.

Dice Pools, Roll Pools, and Reserves

There are six dice boxes to manage Action and Ammo dice. Two for the dice pools themselves, two for assembling the pools to be rolled, and two for the reserved dice.

Action Pools

The ACTION POOL box is automatically populated based on the current BONES, CUNNING, and NERVES scores. These dice will update if those values change.

The + button moves dice from the ACTION POOL to the ACTION box so they can be rolled. The - button moves them back without rolling them. The RESET button moves all of the unrolled ACTION dice back to the ACTION POOL.

The ROLL ACTION! button under the ACTION box rolls the ACTION dice. An option window will pop up to allow the player to set the difficulty (ADVANTAGE, DISADVANTAGE, or SEVERE DISADVANTAGE), then the roll results are posted to the chat. The results table shows the number of dice being rolled, the difficulty level, and the number of successes. Hovering over the SUCCESSES number shows the individual dice rolls.

On the character sheet, the successes are returned to the ACTON POOL and the remaining rolled dice are moved to the ACTION RESERVE. If a critical success is rolled (two or more 6's in a single ACTION roll), an extra die is returned from the ACTION RESERVE to the ACTION POOL.

The REPLENISH button under the ACTION RESERVE returns all of the ACTION RESERVE dice to the ACTION POOL

Ammo Pools

The AMMO POOL is automatically populated based on the currently selected weapon's AMMO level. These dice will update if another weapon is selected, or when a weapon is fired.

The + button moves dice from the AMMO POOL area to the AMMO box so they can be rolled. The - button moves them back without rolling them. The RESET button moves all of the unrolled AMMO dice back to the AMMO POOL.

The FIRE button under the AMMO box rolls the AMMO dice. An option window will pop up to allow the player to set the difficulty (ADVANTAGE, DISADVANTAGE, or SEVERE DISADVANTAGE), then the roll results are posted to the chat. The results table shows the number of dice being rolled, the difficulty level, and the number of successes. Hovering over the SUCCESSES number shows the individual dice rolls.

On the character sheet, the rolled dice are moved to the AMMO RESERVE. If a firearm malfunction is rolled (two or more 1's in a single FIRE roll), the weapon is marked as JAMMED in the weapon table. Clicking on the JAMMED button resets the weapon.

NOTE: The JAMMED button doesn't actually disable the weapon in the character sheet. It is only there to remind the player that they must clear the jam before using that weapon again.

The RELOAD button under the AMMO RESERVE returns all of the AMMO RESERVE dice to the AMMO POOL for that weapon, and updates the AMMO field of the selected weapon in the weapon table.
